什么是 AI Coding VideoWhat AI Coding Video is

AI Coding Video 是让 AI 编程助手写程序来做视频：你用平常的话说想要什么片子，助手写出渲染代码，代码按时间 t 一帧一帧算出画面、合成声音，最后编码成 MP4。画面里没有一张现成的图片，也不调用任何生图、生视频模型。AI Coding Video means having an AI coding assistant write a program that makes the video. You describe the film in plain words; the assistant writes rendering code; the code computes the picture frame by frame from time t, synthesizes the sound, and encodes an MP4. No ready-made images anywhere in the frame, and no image or video generators.

  1. “做一支 3 秒的开场：夜里升起一轮红日，一笔画出一个圆。”"A 3-second opener: a red sun rises at night, and one brushstroke draws a circle."

    你说想要什么You describe it

    内容、风格、时长、横屏还是竖屏。风格可以让 Skill 从词典里帮你挑。Content, style, length, landscape or portrait. The Skill can pick a style from the dictionary for you.

  2. draw(ctx, t) {
  sky(ctx);
  sun(ctx, 0.7 - 0.2 * t);
  stroke(ctx, t / 2);
}

    AI 写渲染代码The AI writes code

    画面是一个以时间 t 为参数的函数；声音是另一段合成代码。The picture is a function of time t; the sound is another piece of synthesis code.

  3. 浏览器按 t 逐帧画The browser draws each frame

    每秒 30 帧，第 n 帧就是 t = n ÷ 30 时的画面。同一个 t 永远画出同一张图。30 frames a second; frame n is the picture at t = n ÷ 30. The same t always gives the same picture.

  4. t = 0.00 s

    编码成视频Encoded as video

    ffmpeg 把帧和声音编成 MP4，横屏 16:9、竖屏 9:16 各一版。ffmpeg turns the frames and sound into an MP4, in 16:9 and 9:16.

第 3、4 步里的小画面不是图片也不是视频，是你的浏览器此刻用上面那个 draw(ctx, t) 现场画出来的。The small pictures in steps 3 and 4 are neither images nor video: your browser is drawing them right now with the draw(ctx, t) above.

  • 可复现Reproducible同一份代码，每次跑出来的片子一帧不差。Same code, same film, frame for frame.
  • 可修改Editable换颜色、换文字、换节奏只是改几个参数。Colors, words and timing are a few parameters.
  • 没有素材版权问题Nothing to license画面和声音都是代码算出来的。Picture and sound are both computed.
