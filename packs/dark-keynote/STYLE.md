# 风格说明：暗色科技发布会

[← 风格包](README.md)

这一页可以整段抄进项目规范。数字以 1080 短边为准，其他分辨率按短边等比缩放（代码里是 `K.u`）。

## 调色板

只有一个品牌强调色，其余颜色都从它推出来或者是中性色。

| 用途 | 颜色 |
|---|---|
| 强调色 | 品牌色（默认 `#8B7BFF`）：当前步骤、重点柱子、下划线、小标题、光边 |
| 强调亮色 | 强调色混 60% 白：大数字渐变底端、标志渐变顶端 |
| 底色 | 外圈 `#05050A`，中心是近黑混 10% 强调色，径向渐变 |
| 网格 | 白 4.5% 透明度，60 像素一格，1 像素线 |
| 正文 | `#F4F5F8`；次要文字同色 60% 透明度 |
| 玻璃卡片 | 白 9% → 2.5% 斜向渐变，1.5 像素白 16% 描边，圆角 28 |

强调色在一帧里只给一个最重要的东西用（当前这一步、最后那根柱子、那个大数字）；其他柱子、已完成的内容用白色低透明度。

## 字体

| 用途 | 字体 | 大小 |
|---|---|---|
| 标题 | 思源黑体 900 | 片头 150–170，段标题 84–92 |
| 正文、字幕 | 思源黑体 700 | 40–46 |
| 大数字 | Bebas Neue | 320–330 |
| 小标题、标签 | JetBrains Mono 700，字距 4，全大写英文 | 20–24 |

## 版式

- 横屏：左文右卡，或左卡右数；文字左对齐在 9% 处。竖屏：标题或大数字在上三分之一，卡片在中段，左右留 90。
- 字幕在横屏底边上方 70，竖屏 86% 高度处（避开平台的按钮区）；信息条在字幕上方（横屏底边上方 300，竖屏 70% 处）。
- 角标：左上标志加品牌名，右上「章名 01 / 05」，边距横屏 64、竖屏 80；开场、章节闪卡、片尾不显示。
- 字幕是代替旁白的说明文字：写画面没写出来的话，不重复同屏的要点；每秒约 4–5 个字；每章一句，放在章节闪卡上，可以跨好几个镜头。
- 卡片顶部有窗口头：三个强调色深浅不一的圆点，右边可放一个等宽小标签。

## 运动

- 所有进场都是「吸附」：`eOutExpo`，0.5–0.7 秒，从下方 60–80 像素或左边 40 像素滑入，同时淡入。不用弹跳、不用旋转。
- 节拍 0.375 秒（160 BPM）：步骤之间隔 2 拍，柱子之间隔 1 拍。
- 每张卡片落定后有一道斜的白色扫光（0.7–0.8 秒）；片头标题的扫光只落在字上。
- 大数字从起始值数到终值，1.2 秒，`eOutExpo`，白到强调亮色的竖向渐变加强调色辉光。
- 转场七种，按镜头的性质挑，相邻两段不用同一种：进章节闪卡、进片尾用光边（斜的强调色光边从左扫到右）；闪卡进本章第一个镜头用推移（横屏往左、竖屏往上，接缝一道强调色细线）；章内一般用叠化（新画面从 1.04 倍缩回并淡入，不淡到黑）；数字落下、开场砸字前用闪白；从一个画面钻进下一个用缩放穿越；代码、文字类用遮罩擦除（新画面从中心的圆里撑开，圆边一圈强调色光）；翻牌、卡片类用翻转（绕竖轴压扁再展开，加一点斜切模拟远近，不做真透视）。都在 0.19–0.375 秒内完成。
- 片子按章走：开场 3–4 个镜头 → 每章一张章节闪卡加 6–8 个镜头 × 4–5 章 → 片尾。一种分镜在一支片子里只出现一次（章节闪卡除外），相邻镜头不用同一类（两张图表、两张卡片墙不挨着）。
- 一个镜头 1.5–2.25 秒，章节闪卡 0.75 秒，片尾 3 秒；时长都是整拍（0.375 的倍数），切点落在拍上。镜头里的东西在 1 秒内到位，到位后停留不超过 0.5 秒就切。
- 镜头层：每个镜头从原大缓慢推近 3.5%，同时往一边平移，单双镜头方向相反；粒子层的光点一直缓慢上浮。
- 背景的柔光一直缓慢漂移，画面不会完全静止。

## 声音

| 时刻 | 音 |
|---|---|
| 全程 | 很低的持续音 + 柔和和弦长音铺底 |
| 片头标志落定 | 重击；标题扫光时一缕高频风声，副标题出现时一声钟 |
| 每一步、每根柱子 | 一个上行的短正弦提示音 |
| 大数字 | 前 1 秒上扬噪声，落下时重击加底鼓 |
| 转场 | 光边：一阵从左到右的带通风声；推移：一阵偏低的风声；叠化：很轻的高频风声；缩放穿越：上扬的风声；擦除：短促的扫声；闪白：一记亮的重击；翻转：两声轻敲 |
| 章节闪卡 | 前 1 秒上扬噪声，章号描边时重击，章名出现时一声钟 |
| 章与章之间 | 铺底一章换一个和弦（同一个调里 I、vi、IV、V）；正文段每 2 拍一记轻底鼓、每拍一下踩镲，章节闪卡和片尾节拍退下只留长音 |
| 其余部件 | 打字一串轻敲击；标注两声上行短音；光标点击一声脆响；翻牌、宫格、表格每格一声轻咔；印章、价签一记闷响；消息、通知、地图上的点每个一声短促提示音；渲染进度每格一声，走完一声钟；对比卡片落定一记闷响；引用一声长钟；片尾重击加和弦钟声 |

全部由 `synth.py` 合成，不用录音、曲库或 AI 配乐。

## 禁止项

- 第二个强调色、彩虹渐变、霓虹多色。
- 弹跳、旋转、翻页，带真透视的 3D 翻转。
- 浅色底或纯黑无网格的底。
- 一屏超过一个巨大数字，或一张卡片超过 5 条步骤。
- 一个镜头拉到 3 秒以上来凑时长，或同一种分镜在一支片子里出现两次。
- 衬线字体、手写体；中文用斜体。
- 照片、图库图标、第三方 Logo。
