# 电商带货：北山制包所《旷野》布丁包上新讲解

[← 案例目录](../README.md)

- **场景**：原创设计的小品牌上新一款包，要一条 4–5 分钟的上新讲解（商品详情页主图视频、店铺首页、视频号、直播间回放）；过程文件留着，以后分化或混剪成 15 秒投流短片。外景模特拍摄要请模特、摄影、跑外景，补一个镜头就得再拍一次。
- **商品**：真实品牌、真实商品：北山制包所（BEISHAN STUDIO）《旷野》系列布丁包。维护者是品牌方，人物和商品图由维护者提供（见 [cases/README.md](../README.md)「规矩」的例外）。内容来自策划 [plans/shop-handbag/plan.md](plans/shop-handbag/plan.md)，交接格式 2。
- **主角**：G 类。旷野的梦、包在草地上、手拎包、装包、11 色的场景都是生成的；C 类做露珠变圆珠的形变、部件和皮革剖面、尺寸和价格；T 类是品牌方的模特图、细节图、颜色款式图做推镜和视差。
- **讲法**：画外旁白（公开女声，不对口型）。前半（P1–P3）像短片：慢、安静、风声、段内硬切，每段自成一块，方便以后拆开混剪；后半（P4–P10）像讲解员：数字上屏，语气克制，不喊「买它」。

## 规矩

- 模特的脸不送进生成模型：人物镜头只用原图做 T 类合成（推镜、视差）；生成的画面里有人只出手、背影、远景。生成的视频不带原声。
- 生成的画面里出现包时，以品牌方的颜色款式图、细节图为参考生成，生成后逐张对照原图看形状、珠子数和配色，对不上的不用。
- 文案照广告法（策划 content.md 的 P1-4、P1-5）：不用「最」「第一」「顶级」，不加耐用、防水、不掉色这类功效宣称；品牌自己说的（灵感、设计来历、须知）讲成「北山说」「北山提醒」。
- 不说「已售」、不提平台服务、不点第三方摄影师的名字、不说「虚构」；片尾写「素材由品牌方提供」。

## 全片统一

案例的 `case.json` 不写 `unify`（格式见 [cases/README.md](../README.md)），这一层记在这里：

| 项 | 定的 |
|---|---|
| 色板 | 从品牌图里取：枯草黄 `#C9A86A`、晴空蓝 `#9DB7C9`、河水灰绿 `#7E8B74`、奶白底 `#F4EFE6`、墨色字 `#2A2622`；强调色只用当段那只包的颜色 |
| 字体 | 标题思源宋体（衬线，配「旷野」的复古）；数字和正文思源黑体；品牌字 BEISHAN 用图里的原样字标 |
| 字幕 | 底部三分之一、奶白字加淡阴影，一句一行；前半只在关键词出大字，不跟全句字幕；后半跟旁白逐句 |
| 转场 | 前半硬切；后半段内交叉溶解 0.4 秒，段和段之间硬切（方便拆开混剪） |
| 配乐 | 一条安静的原声吉他或钢琴（CC0、公共领域或 CC BY），前半压低、叠风声和草叶声；后半音乐稍起，数字上屏时一声轻的「嗒」 |
| 旁白 | 公开女声、语速 1.0（`script.json` 的 `voice`），先试听 2–3 个再定，全片一个 |

典型样片：P2（旷野里的白日梦，前半短片、生视频最多）和 P6（皮料和配件，后半讲解、代码剖面加细节图加生成微距）。

## 素材

- 品牌方给的：头图 5、商品介绍 4、模特长图 7、细节图 8、颜色款式图 11，在策划的 `plans/shop-handbag/source/brand/`（对照表 `files.md`）；出片时拷进 `assets/`，`assets.json` 每份标「维护者自有」。
- 生成（青水）：旷野镜头、包在草地上、手拎包、装包步骤、皮面微距、11 色场景、旁白，见下面「用量」。生成前把提示词和参考图给维护者看过再调。
- 配乐和风声：CC0、公共领域或 CC BY，出处和许可记进 `assets.json`。

## 降级用法

<!-- gen:downgrade -->
- 不用生视频：旷野镜头改成生图加推拉、代码画风和光尘，省六七十算力；少了「风真的在吹」的那几秒。
- 不用生成：只用品牌方的图做 T 类推镜、代码画线稿和数字，成了一条图文讲解，前半的「梦」讲不出来。
- 第 7 段（11 个颜色）：不生成场景图，只用颜色款式图排格子，这一段改归 C 类，G 的时长跟着少。
<!-- /gen -->

## 待核

- 生成的包和原图对不对得上（形状、珠子数、配色），每张生成后对照。
- 配乐和风声的许可，选定后附链接。

## 对比口径（写说明时用）

<!-- gen:compare -->
- 传统人工：电商商品视频的厂商报价从几百到上万美元一条不等，批量拍摄能压低单价（[Bambuser 的预算指南](https://bambuser.com/article/video-production-cost-ecommerce-guide)、[Vidico](https://vidico.com/news/product-video-cost/)，厂商报价，写说明时逐条核原文）；国内接单价见[人人都是产品经理整理的 50 条报价](https://www.woshipm.com/?p=6478410)（作者自述，样本偏差大）。外景模特拍摄要另算模特、场地和差旅。
- 过去的 AI 工具：「商品图 + 提示词」一键出广告片的平台，出得快，但每改一处要整条重新生成；包的尺寸、材质这类要讲准的信息，生成画面讲不准。
- 本方法：取 `log.md` 的实际记录；真人镜头用品牌方现成的模特图，不另外拍。
