# 真实应用案例

[← 返回说明](../README.md)

## 目录结构

```
cases/<名字>/
  README.md        场景、分镜、技术清单、用量（策划）；做完后补「制作记录」
  case.json        介绍页读的数据：标题、一句话、时长、封面、用到的风格编号和技术标签、对比表、降级用法
  script.json      旁白稿：分段，每段对应分镜的一段
  assets.json      素材清单，字段和样片的一样（见 samples/tools/assets.py 开头）
  assets/          素材
  segments/        每段一个场景文件，写法和样片的 scene.js 一样，直接用 samples/lib/lib.js
  sound.py         整支的混音：旁白、配乐、音效
  log.md           制作记录：每一步用时、生成用量、返工
```

## 规矩

- **场景要真实存在**：选的是有人在做、有人在付钱的那类视频；品牌、商品、讲师是虚构的要在片尾和说明里写明。
- **素材**：同样只用公共领域、CC0 和 AI 生成的，G 类不生成真人；T 类的公共领域历史影片里有人物的照原样用（需求方定）。
- **素材进不进仓库**：能从公开地址重新下载的不进仓库，`assets.json` 记下载地址和截取参数，`assets.py` 拉下来再处理；生成的素材和处理过、没法重新下载的进仓库，每支合计不超过 30 MB。不受样片 10 MB 的限制。
- **成片放 Release `media`**：每支一个原版（1080p，不超过 120 MB）、一个中版（长边 1280，不超过 25 MB）、一张封面（长边 1280 的 JPG）；投流短片之类的附带成片也放进去。用 `scripts/media.py` 上传，清单记在 `media.json`。
- **出片**：分段渲染再接起来。每段 10–60 秒，单独渲染、单独检查（画面不动、无声、体积），整支只接一次、混一次音。每帧只由时间 t 决定。
- **数字和事实**：旁白和画面上的每个数字，在 `script.json` 里记出处链接；虚构的规格写明「虚构」。
- **制作记录照实写**：`log.md` 记每一步的实际用时（人在等、人在改、机器在渲染分开记）、青水和 DeepSeek 的用量、返工次数。介绍页对比表里「我们」那一列只取这里的数。
- **对比数据**：别人的用时、费用引用公开来源，标「作者自述」或「厂商报价」，附链接；找不到就写「没查到」，不估。
- **降级用法**：每支写清去掉哪些技术还能做出简化版，并说明缺了什么。

## 介绍页模块

- 放在页面最底下，3 张卡片：封面、标题、时长、一句话。点开是播放器，先放中版，另给原版链接；没点开之前只加载封面。
- 卡片展开后三栏：用到的技术（风格编号和技术标签，都能点到对应样片）、对比表（用时、费用、可修改性、可批量性 × 传统人工 / 过去的 AI 工具 / 本方法）、降级用法。
- 数据从各案例的 `case.json` 读，由 `site/build.py` 生成；只改 `site/` 和 `cases/`，不动 `skills/`、`samples/`。
