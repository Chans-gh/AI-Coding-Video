# 选风格索引

[← 返回说明](README.md)

## 怎么用

选风格分三步，一般几分钟就能定下 2–3 个候选。

1. **写下需求**：这支片子的题材、用途、观众、想要的情绪、发布平台，以及手上有什么素材。
2. **查索引**：在下面六张表里各找对应的一行，几张表里重复出现的风格就是首选。例如“给小学生讲水循环、做成可循环的课堂素材”，题材、受众、格式三张表共同指向无缝循环科普插画和科普扁平。
3. **取提示词出片**：点风格名跳到条目，有样片的先看样片确认气质，复制那句风格提示词，填进[提示词方法](prompting.md)里的通用模板，并按条目的技术标签选好制作路径。

选好风格后，配乐、音效和旁白音色到[声音篇](sound.md)查。
