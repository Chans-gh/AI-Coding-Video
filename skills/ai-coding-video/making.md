# 出样片与做风格包

[← 返回 SKILL](SKILL.md)

讲 1 级（样片）和 2 级（风格包）具体怎么做。提示词怎么写看 [prompting.md](prompting.md)，配声音看 [sound.md](sound.md)。下面提到的代码都随本 Skill 一起安装：`samples/`（出片工具和每个已验证风格的样片代码）、`packs/`（风格包），不用联网取。

## 动手之前

1. **确认技术路径在用户项目里跑得通**：要浏览器（Canvas 2D、WebGL、SVG）就确认有 Chromium 或 Playwright；要 GPU 就确认 WebGL2 能开；要配声音就确认有 Python 和 numpy、scipy；出视频要 ffmpeg。缺什么先说，不要写到一半才发现。
2. **优先改现成代码**：条目有「样片代码」的，从 `samples/<编号>/` 改，比只拿提示词重写稳定得多；有「风格包」的，直接用 `packs/<名字>/`。只有「技术（建议）」的条目没人验证过，要向用户说明效果靠试。
3. **用用户的真东西**：品牌色、字体、产品名、真实的一句文案。用占位文字做出来的样片，用户很难判断合不合适。

## 1 级：样片

目标是 3–5 秒、横竖两版，让用户判断「这个风格放在我的项目里像不像样」。

### 自带的出片工具

用户项目已经有 Remotion、Motion Canvas 这类管线的，用它自己的，样片代码只当画法参考。没有的，用本 Skill 自带的这套：

```bash
cp -R <本 Skill 目录>/samples ./video     # 拷进用户项目再改，不要直接改 Skill 安装目录（更新 Skill 会覆盖）
cd video && npm install                  # 字体和绘图库装进 node_modules/，出片时从本地载入，不联网
export AICV_SKILL=<本 Skill 目录>          # new.py 从这里读风格条目
python3 batch.py C-013 --quick           # 先原样跑通一个样片，确认环境没问题
python3 new.py C-013                     # 或：给还没有样片的风格起骨架（已有的文件不覆盖）
```

要 Node.js 18 以上、Python 3（Playwright 并装好 Chromium、Pillow、numpy、scipy）和 ffmpeg；浏览器可用环境变量 `CHROME` 指定。函数速查见 [samples/API.md](samples/API.md)，`batch.py` 的用法写在它文件开头。T 类、G 类样片只带了代码和 `assets.json`（素材清单），素材本身不随 Skill 安装：T 类可以照 `assets.json` 用 `tools/assets.py` 重新下载，G 类要用户按 [materials.md「配置生成服务」](materials.md#配置生成服务) 配好服务再生成，或换成自己的素材。

**改的顺序**（照这个来，比从零设计稳）：

1. 拷对应风格的 `samples/<编号>/`，原样跑通 `--quick`（画面和声音都过）。
2. 换内容：题材、主体、文字、品牌色、时长，一次只改一处，每改一处跑一次 `--quick`。
3. 声音单独试：`python3 batch.py <编号> --sound`，别等画面全做完才第一次跑。
4. 画面都对了，再加细节。**细调最多 3 轮**（一轮 = 改一处、跑一次 `--quick` 看截图）：3 轮后不管满不满意，先去掉 `--quick` 出完整的横竖两版交给用户，把还想改的地方列出来，由用户决定要不要再调。不要停在半成品。

**哪些照用、哪些自己来**：

| 层 | 内容 | 怎么对待 |
|---|---|---|
| 管线 | `lib/lib.js`、`lib/synth.py`、`batch.py`、`render.py`、`player.html` | 照用，不要重写；时间驱动、截帧、合成声音、自检都在里面 |
| 画法 | 样片里怎么做出这种风格：镂空、光照、纹理、笔触、分层、运动方式 | 可以借，按用户的主体重新组合 |
| 内容 | 样片里的角色、场景、构图、配色、文字、配乐旋律 | 换成用户自己的；样片只是示范，主体和构图不能和样片一样 |

### 写法

- **每帧只由时间 t 决定**：画面写成 `draw(t)`，不依赖上一帧的状态，不用 `Math.random()`，随机数用带种子的发生器。这样可以任意跳帧检查，逐帧导出也不会掉帧、错位。
- **横竖两版分别构图**：竖版不是横版裁出来的。主体在横版里左右排，到竖版里通常改成上下排；字号、留白按短边缩放。
- **先定节拍**：入场、强调、收尾落在拍点上，声音也按同一个拍子放。本库样片用 160 BPM（一拍 0.375 秒，3 秒正好 8 拍）。
- **标志元素要画出来**：提示词里写的 3–5 个标志元素每个都要在画面里认得出，禁止项一条都不能出现。
- **文字**：中文要折行（标点不放行首），字体等加载完再画第一帧，长句在竖版里会不会挤出画面要单独看。

参考写法：[样片骨架和 API](samples/API.md) · [一个完整样片（C-044）](samples/C-044/) · [合成器 synth.py](samples/lib/synth.py)

### 出片和自检

逐帧截图再用 ffmpeg 合成视频，是最不挑环境的办法；用户项目已经有 Remotion、Motion Canvas 这类管线的，就用它自己的。交给用户之前自己先查一遍：

- 先看数字：时长、帧数、文件大小、首帧和末帧是不是全黑或全白。
- 再看抽帧拼图：每隔半秒到一秒取一帧拼成一张图，一眼看出节奏和构图。
- 只有可疑的那几帧才单独放大看：文字出界、元素重叠、竖版挤压、字体没加载成方块。
- 和风格的缩略图 `images/<编号>.jpg` 并排看：标志元素认不认得出；主体不该被做成虚的、糊的（只有提示词要求的地方才虚化）。
- 和样片 `samples/<编号>/` 的画面比：主体、构图要是用户自己的，不能只是换了颜色的样片。

### 交付

横屏 16:9 和竖屏 9:16 各一段视频，加一张抽帧拼图。一次给 2–3 个候选，每个附一句「为什么选它」，让用户挑。用户点头之前不要往下做 2 级。

## 2 级：风格包

用户通过的风格，做成一套能反复用的代码，加一份写进项目规范的风格说明。以后这个项目的视频都按它来，换内容不换风格。本库的范例是 [dark-keynote 暗色科技发布会](packs/dark-keynote/)，下面的做法都能在它里面找到对应代码。

### 包里有什么

| 文件 | 是什么 |
|---|---|
| `pack.js` | 主题和部件 |
| `sound_kit.py` | 每种部件出现时放什么音，外加一段铺底 |
| `STYLE.md` | 风格说明：调色板、字体、版式、运动、声音、禁止项 |
| `meta.json` | 名字、部件清单、几种演示用的品牌色（第一种是默认色） |
| `demo/` | 演示片：把所有部件排成一支 15 秒左右的短片，每种品牌色各出横竖两版 |

### 五条做法

1. **一个品牌色推出整套配色**：主题函数只收一个品牌色，背景、文字、辅助色、光晕都从它算出来（调亮度、调饱和度、取补色）。换品牌只改这一个参数。做完要拿至少三种差别大的颜色（比如紫、橙、绿）试，看哪种会脏、会看不清。
2. **部件只管自己那一段**：每个部件的签名都是 `(画布, 主题, 本地时间, 内容)`。本地时间从这一段开始时算 0，可以是负数（还没开始）。部件负责自己的入场和停留，不负责离场，离场交给转场。
3. **用分段表排片子**：一支片子就是一张表，每行是「从第几秒开始、用哪个部件、放什么内容」。每帧先查表找到当前段，再把本地时间传给部件。改顺序、加一段、调时长都只改表。
4. **转场拿两个整帧**：转场函数收「前一段的画法」和「后一段的画法」，在进度 0–1 之间把两者混起来（擦除、推移、光边）。这样任何两个部件之间都能接，部件自己不用知道前后是谁。
5. **字幕和声音跟分段表同一条时间轴**：字幕是一串「开始、结束、文字」，最后叠在最上层，放在横竖两版都安全的区域。声音按同一张表的时刻放：每个部件一个入场音效，加一段贯穿全片的铺底，都在同一个调上。

通常要覆盖的部件：片头、讲解（分步骤）、数据（柱状和大数字）、转场、字幕。用户项目里常出现别的画面（比如人物介绍、代码演示），就再加对应的部件。

### STYLE.md 写什么

写给以后做这个项目视频的人和 AI 看，每条都要能照着检查：

- **调色板**：品牌色怎么推出其他颜色，背景、文字、强调各用哪个，强调色在一个画面里最多占多少。
- **字体**：标题、正文、数字、等宽各用什么，字重和字号比例。
- **版式**：栅格、安全区，横竖两版各自的主体位置。
- **运动**：用哪几种缓动，入场时长，节拍，什么动作落在拍点上。
- **声音**：铺底和音效的音色、调、音量关系。
- **禁止项**：这个风格里绝对不能出现的东西（比如第二个强调色、圆形图标、弹跳缓动）。

写好后在用户项目的规范文件（`AGENTS.md`、`CLAUDE.md` 之类）里加一行链接到它，不要整份复制，免得两处不一致。

### 交付

每种品牌色的横竖两版演示片（让用户自己切换着比）、部件清单（每个部件的调用方式和内容字段）、STYLE.md。用户看过演示片点头，风格包才算定下来。
