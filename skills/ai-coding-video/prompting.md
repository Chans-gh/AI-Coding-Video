# 提示词方法与制作路径

[← 返回说明](README.md) · [选风格索引](index.md)

## 怎样用提示词控制风格

只写风格名，结果常常退化成通用的扁平矢量动画。真正起作用的是下面 8 个要点，写得越具体，风格越稳。

1. **制作路径**：写明“纯代码逐帧（Canvas/SVG/WebGL），不用图像或视频生成模型”，或者“画面由 Seedance/Kling 生成，AI 助手负责分镜和每个镜头的提示词”。同一句“水彩风”，路径不同，结果完全不同。
2. **风格名 + 3–5 个标志元素**：纸张或材质、限定调色板（写色值，或“只用黑色加一个红”）、线条性质、留白比例、字体。[风格条目](index.md)里每种风格都有一句写好的风格提示词（已渲染的还配了样片），可以直接复制。
3. **运动语言**：帧率（角色一拍二 12fps、镜头 24fps 是手绘感的关键）、缓动（预备动作、过冲、错峰），以及禁止项（如“不要弹跳缓动、粒子、发光”）。
4. **本风格独有的转场**：墨晕开进入下一场、纸页折叠、网格扫过。指定一个，放在情绪高潮处。
5. **镜头语言**：像展开卷轴一样横移、高角度俯视、推拉、一镜到底、结尾拉远揭示全貌。
6. **声音**：配乐乐器、音效要跟材质走、有无旁白（语言和语气）；也可以给自己的音乐，让它按节拍剪。
7. **参考作品**：给一两部作品或一张图，写清“学什么（构图、节奏、配色逻辑）”和“不学什么（角色、旋律、Logo）”。一张参考图胜过十句描述。
8. **规格与验收**：时长、画幅（16:9、9:16、1:1）、分辨率、帧率、字幕语言；要求先出分镜和样片，再做最难的 2–4 秒样片，最后出整片，每一步都用抽帧拼图自检。

通用模板（方括号换成你的内容）：

```text
用【风格名】风格做一支【45】秒、【16:9】、1920×1080、24fps 的短片，主题是【主题】，给【受众】看。

制作路径：纯代码逐帧渲染（Canvas 2D / WebGL + 无头浏览器 + ffmpeg），不用任何图像/视频生成模型和素材库。

风格标志（每一帧都要看得出来）：
- 材质/纸张：【…】
- 调色板：【最多 N 色，写出色值】
- 线条/笔触：【…】
- 运动：【角色一拍二 12fps，镜头 24fps；有预备动作和过冲】
- 转场：【本风格独有的转场，放在高潮】
- 字体：【Google Fonts 字体名，需支持中文】
禁止：【粒子、发光、弹跳缓动、照搬任何现成角色或 Logo】

参考：【作品名】——学它的【构图/节奏/配色逻辑】，不学角色和音乐。
故事：一个主体、一个目标、一个转折；前 3 秒要有钩子；结尾呼应开头。
声音：【配乐乐器/风格】；音效跟材质走；【旁白语言与语气 / 无旁白】；字幕烧录并导出 .srt。

流程：先给我分镜表和 3 张风格样片 → 再渲染最难的 3 秒 → 最后整片。每一步抽帧拼成一张图自检，对照上面的风格标志逐条检查。
```

## 先选制作路径

写代码的 AI 助手本身只输出文字和代码，最终画面来自它写的渲染程序、它调用的工具或其他模型。本库目前只收「纯代码」一类（C），对应下表第 1、2、3、6 条路径；第 4、5、7 条要用 AI 生成素材（G）或第三方素材（T），这两类以后收录。写实人物和自然表演基本要靠第 4 条。

| 路径 | 本库分类 | 能做出的风格 | 提示词里怎么锁定 | 主要局限 |
|---|---|---|---|---|
| 1. 代码逐帧 2D（Canvas / SVG / p5.js / WebGL） | C | 手绘、版画、纸艺、排版、像素等绝大多数风格 | “纯代码逐帧绘制，每帧由时间 t 唯一决定，不用生成模型和外部图片” | 写实人脸、自然动作弱；长片角色容易走样 |
| 2. 讲解框架（Manim / Remotion / HyperFrames + GSAP） | C | 公式推导、图解、字幕卡、产品动效 | “用 Manim 做画面、edge-tts 配音，字幕和旁白用同一条时间轴” | 公式、事实、发音要人工核对 |
| 3. 3D 与实时图形（Three.js / WebGL / Blender） | C | 低多边形、写实渲染、爆炸图、科学可视化 | “Blender 程序化建模，无预制资产；先出灰模和镜头预览，再做材质” | 渲染慢，有穿模、闪烁 |
| 4. 外部视频模型（Seedance / Kling / Runway / Veo） | G（后续） | 写实人物、电影感广告、伪纪录片 | “AI 助手写角色设定表和每镜首帧/末帧描述，画面由【模型】生成” | 跨镜头人物一致性、生成费用 |
| 5. 改编已有素材 | T（后续） | 口播重绘、剪辑加花字、文章转视频、产品截图广告 | “以我提供的原片为唯一影像来源，保持原声、字幕和时长” | 素材授权 |
| 6. 程序/游戏录屏 | C | 可玩游戏、交互模拟器 | “先做一个可交互的 HTML，再录制 60 秒演示” | 录屏节奏不如分镜动画 |
| 7. 混合 | T / G（后续） | ComfyUI、Suno 配乐、ElevenLabs 配音等组合 | 逐项写明哪个工具负责哪一部分 | 流程长，费用分散 |

## 三个完整示例提示词

分别对应两条最常用的纯代码路径：代码逐帧艺术风格、讲解框架做产品发布。

**示例 1：纯代码水墨短片**

```text
用中国水墨写意风格做一支 45 秒、16:9、1920×1080、24fps 的短片，主题是「一个茶农在雾里采第一批春茶」。
制作路径：纯代码逐帧（Canvas 2D + WebGL 合成宣纸），不用图像/视频生成模型，不用外部图片。
风格标志：
- 暖色宣纸（约 #F2ECDE），有纸纤维和墨色晕开；画面 60–80% 留白，留白就是雾和天空
- 墨分五色，只用黑灰；全片唯一的红是结尾的朱印和人物身上一个小物件
- 笔触有湿有干，高潮处用一笔飞白
- 场景之间用墨滴晕开过渡，不用硬切和淡入淡出
- 人物一拍二（12fps），镜头和墨晕 24fps
镜头：开场是一张空白宣纸，一滴墨落下晕成山；像展开手卷一样从右往左横移；结尾拉远看到整幅长卷，盖印。
声音：古琴为主，箫作点缀，雨声和脚步声；高潮前留 2 秒完全静音。无旁白，字幕像题跋一样写在留白处。
参考：上海美影厂《山水情》——学留白、墨晕和古琴节奏，不学它的角色和配乐。
流程：先给分镜表 + 3 张样帧 → 渲染最难的 3 秒 → 整片。每步抽帧拼图，对照风格标志逐条自检。
```

**示例 2：暗色科技风产品发布片**

```text
为我的 App【名称】做一支 20 秒、16:9 的发布短片，风格是暗色科技发布会。
素材：代码仓库在【路径】，截图在【路径】，品牌色【色值】。只展示仓库里真实存在的功能，不编造数据和用户评价。
制作路径：Remotion（或 HyperFrames + GSAP）渲染，保留可编辑工程。
风格标志：近黑渐变底 + 发丝细网格；只有一个品牌强调色；界面元素按网格吸附运动，用克制的弹簧动画；一道扫光揭示产品；最后用一个巨大的数字说出核心价值。
禁止：弹跳缓动、粒子、镜头光晕、渐变按钮、库存图标。
声音：极简电子节拍，UI 音效落在节拍上。
流程：先读代码列出 3 个可展示的真实能力 → 写 5 镜分镜 → 低清预览给我确认 → 1080p 导出。
```


另装了现成风格库 skill 以后（见 [sources.md](sources.md)），一句话就够了，如：“用积木玩具风格做一支 40 秒的片子，讲我们团队从零搭出第一个产品，中文旁白。”风格细节由该风格的 STYLE.md 补全。

## 常见翻车与对策

多数问题都能在提示词里提前防住；写实人脸和自然表演则需要换路径。

| 问题 | 原因 | 提示词里怎么防 |
|---|---|---|
| 出来的样子很通用，看不出风格 | 只写了风格名 | 写 3–5 个标志元素 + 禁止项 + 一部参考作品 |
| 手绘笔触每帧闪烁、线条“爬动” | 每帧随机数不同 | 要求固定随机种子、角色一拍二、笔触噪声按归一化弧长生成 |
| 长片里角色越画越走样 | 没有角色规范 | 开工前先出角色设定表（转面、表情、姿势、配色），每段对照它自检 |
| 写实人脸、自然动作僵硬 | 代码路径的短板 | 换风格（往插画、3D 卡通靠），或改走外部视频模型路径，AI 助手只做分镜和提示词 |
| 字幕溢出、音画不同步 | 字幕、旁白、画面各自计时 | 字幕和旁白用同一份时间轴生成；要求按目标尺寸抽帧检查 |
| 公式、数字、史实错 | 模型凭记忆填内容 | 先列事实主张和来源让你确认，数字只从你给的数据里取 |
| 一次出片不满意 | 好片本来就要多轮 | 预留迭代；有作者自述一支 45 秒短片用了 163 次模型调用、约 6 小时 45 分 |
| 声音廉价 | 用了通用音效 | 指定乐器和结构，音效跟材质走，禁用通用 whoosh；关键处要求真正静音 |
