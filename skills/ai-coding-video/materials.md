# 用素材做视频：T 类和 G 类

[← 选风格索引](index.md) · [T 类条目](styles/footage.md) · [G 类条目](styles/generated.md) · [提示词方法](prompting.md) · [声音](sound.md)

C 类的画面全部由代码算出来。有些视频光靠代码做不出来：要真人口播、真实产品、真实地点和数据，或者要写实的人物和场景。这时候就把素材交给代码，由代码排版、剪辑、加动效、配字幕，再出片：

| 分类 | 素材是什么 | 用户常见的说法 |
|---|---|---|
| C 类：纯代码 | 没有素材，画面全部由代码算出 | 「做个动画讲讲这个概念」 |
| T 类：真实素材 | 录像（含口播）、录屏、照片、数据（表格、地图、卫星图、点云）、三维模型（开放许可的网格和贴图） | 「用我拍的视频剪一下」「把这份数据做成片子」 |
| G 类：AI 生成素材 | 生图、生视频、语音合成；可以搭配 T 类的素材（如 CC0 三维模型），出处、许可照 T 类记 | 「做个写实的广告」「来段动漫短剧」 |

T 类、G 类按**内容类型**分（用户要做的是哪种视频），同一个内容类型两类都有做法，取值见 `data/tags.json` 的 `content_types`。先在 [index.md](index.md) 的「按内容类型」表里找到那一行，再看 T、G 两列各有什么。每个条目都标出用到了哪几种素材，用户手上有什么就挑什么。

## 怎么做（不管用哪家服务）

1. **先列素材清单**：每份素材一行，写清文件、种类、出处或生成参数、许可、在片子里的哪几秒用。本库的样片用 `assets.json` 记，字段见 [samples/tools/assets.py](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/tools/assets.py) 开头的说明。
2. **统一处理再进代码**：视频统一帧率（本库是 30 帧/秒）、去掉声音另存；图片缩到用得着的大小；数据只留要用的列和行。代码按帧取素材：第 k 帧取素材里的第 k 帧，不边播边拿，这样每帧只由时间 t 决定，同一份代码每次出的片子都一样。
3. **剪辑和动效写在代码里**：镜头从素材哪一秒开始、放多快，写成一张表；字幕时刻从语音合成返回的逐字时间里算出来，不手对。
4. **声音分三层**：旁白或原声、配乐、音效。说话时把配乐压低 40–60%。
5. **出片前查一遍**：时长、横竖两版、体积；素材的元数据（拍摄设备、地点、软件）去掉；片尾或角落写清素材的出处。

## 统一处理

素材进代码之前做的处理是**工序**，不是风格类型，也不单独成条目；要做哪几道，看素材和成片的要求（统一帧率、去声音、缩图见上面「怎么做」第 2 步）：

| 工序 | 什么时候做 | 做法 |
|---|---|---|
| 超分 | 素材分辨率低于成片 | ESRGAN 一类的超分模型；先在小片段上试，免得放大噪点 |
| 补帧 | 素材帧率低，慢放会卡 | RIFE 一类的补帧模型，或 ffmpeg 的 `minterpolate`（快但容易糊） |
| 去噪 | 夜景、老胶片、压缩痕迹重 | ffmpeg 的 `hqdn3d`、`nlmeans`，或模型去噪；老片的颗粒是风格时就别去 |
| 重新打光、调色 | 几段素材明暗色调不一 | 先统一色调再进代码；要改光源方向才用重打光模型 |
| 深度图 | 做分层视差、景深、雾效 | 单目深度模型（如 Depth Anything V3）出 16 位深度图，存成素材旁的另一份文件 |
| 抠图、分割 | 要把人或物从背景里分出来 | 分割或抠像模型出带透明度的图或遮罩，同样存成另一份文件 |

处理后的文件和原文件都记进素材清单，写明做了哪道工序、用了什么工具，按需要复现。

## T 类：素材从哪来

- **用户自己的**：口播、产品录屏、活动照片、业务数据。只用用户确认有权用的。
- **公共领域和开放许可**：NASA 图片视频库、美国国会图书馆（标为 No known restrictions 的）、NOAA 等美国政府机构的数据、Natural Earth 地图数据、Project Gutenberg 和 archive.org 上过了版权期的书和影片、Wikimedia Commons 上标为公共领域或 CC0 的。每份都要回到出处页面核对许可，不靠搜索结果里的标签。
- CC BY 要署名；CC BY-NC、CC BY-ND 和「仅限个人使用」的不能拿来商用或改编，换一份。
- 素材里有人物的，照出处原样使用，不另外加姓名、年龄、住址等个人信息。

## G 类：怎么生成

- 任何生图、生视频、语音合成服务都可以，选用户已经在用的那家，配法见下面「配置生成服务」。模型名、参数和提示词记在每个样片的 `assets.json` 里。
- **先用最便宜的模型试**：构图、动作、镜头对了，再换好模型出正式版。每支 8–15 秒的片子，一般几张图、一两段视频就够，剩下交给代码剪辑和动效。
- **同一角色前后一致**：先生成一张定妆图，之后的生图、生视频都拿它当参考图或首帧。
- **帧率**：生视频模型常出 24 帧/秒（例如 Seedance），统一成 30 帧/秒时会有少数帧重复；推拉、慢放的镜头只要看着不卡就不用处理，卡了再换插帧或改用素材原帧率出片。
- **音画同生**：有的生视频模型连声音一起生成（例如 Seedance 2.0）。素材清单里另记一份「原声」，`of` 写那段视频的文件名，工具从生成的原始视频里取出音轨；视频本身进仓库时不带声音。
- **不出现真实品牌**：提示词里写「没有文字、没有标志」；生成结果里还是冒出了真实品牌字样的，局部模糊或裁掉，改了什么记在素材清单里。
- **不生成真实人物**：提示词里不写真人姓名、不描述可辨认的真人长相，也不克隆真人声音；旁白用服务提供的公开音色。
- 生成结果只留文件本身：账号、Key、任务编号、带签名的下载链接不要写进代码和文档。

## 配置生成服务

生图、生视频、语音合成、生成矢量四类分开配，各用一个环境变量指定一条「适配命令」：拿到任务（提示词、模型、参数、参考图），调用户那家服务，把文件存下来。只用到哪类就配哪类。

| 类 | 环境变量 | 可选 |
|---|---|---|
| 生图 | `AICV_IMAGE_CMD` | `AICV_IMAGE_MODEL`：换模型 |
| 生视频 | `AICV_VIDEO_CMD` | `AICV_VIDEO_MODEL` |
| 语音合成 | `AICV_TTS_CMD` | `AICV_TTS_MODEL`、`AICV_TTS_VOICE`：换模型、换音色 |
| 生成矢量 | `AICV_SVG_CMD` | `AICV_SVG_MODEL`：语言模型照提示词写 SVG 图标、线条图，代码再按每一笔做描边动画；素材清单里文件名以 `.svg` 结尾的就走这一类，种类仍记「生图」 |

- **用户要做的**：在那家服务开通账号、拿到 Key，把 Key 设成服务自己要求的环境变量（例如本机 shell 的 `export`，或云端环境的环境变量设置）；不要贴进对话，不要写进代码和文件。
- **AI 助手要做的**：照用户那家服务的 API 文档写一条适配命令（几十行），输入输出的约定写在 [samples/tools/gen.py](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/tools/gen.py) 开头；写法可以照 [samples/tools/adapters/placeholder.py](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/tools/adapters/placeholder.py)，它不调任何服务、只出占位素材，先配它能把整条流程跑通。配好后跑 `python3 tools/gen.py` 看各类的状态，`python3 tools/gen.py try image` 试一次（会真的调一次服务）。
- **没配置时**：那一类不生成，只提示要配哪个环境变量，其余素材和出片照常；不报错、不中断。先告诉用户缺哪一类、去哪里配，或者改用用户自己的素材。
- **安全**：Key 只由适配命令从环境变量读，不打印；服务返回的任务编号、带签名的下载链接、原始响应只留在 `out/`（不进仓库），交出去的文件只有素材本身。

默认推荐的服务（用户已经有别家的，用那家）：

- 生图：[Google Gemini API 的图片生成](https://aistudio.google.com/docs/image-generation)
- 生视频：[火山方舟的 Seedance 视频生成](https://docs.volcengine.com/docs/82379/1520757)
- 生成矢量：[DeepSeek API](https://api-docs.deepseek.com/)（对话接口，让它只回一段 SVG；关掉深度思考，不然长度用在推理上，回不出图）
- 语音合成：[MiniMax 语音合成](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)（带逐字时间，字幕能直接对上）；不想用云端服务的，用 [sound.md](sound.md) 里的本地 Kokoro

## 声音素材

- 旁白：语音合成的公开音色。数字、年份、外文缩写先写成念法（「一九七二年」），字幕上再换回「1972 年」。合成后回听一遍。
- 配乐、音效：公共领域、CC0，或 CC BY 并在片尾署名。只许「在作品里使用」、不许单独再分发音频文件的曲库，不要把文件放进公开仓库。
- 选曲和旁白音色的方向见 [sound.md](sound.md)。

## 本库样片里的做法

- 素材下载、生成、统一处理、去元数据：[samples/tools/assets.py](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/tools/assets.py)；生成经 [samples/tools/gen.py](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/tools/gen.py) 交给上面配的适配命令。
- 画面里读素材（图片、按帧取的视频、CSV、字幕）：`samples/lib/lib.js` 的 `loadAssets`、`loadImage`、`loadVideo`、`parseCSV`、`cueAt`、`caption`，说明见 [samples/API.md](https://github.com/Chans-gh/AI-Coding-Video/tree/main/samples/API.md)。
- 声音照素材清单摆放、说话时压低配乐：`samples/lib/synth.py` 的 `assets()`。
