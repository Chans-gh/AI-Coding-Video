# 代码驱动的外部程序（1 种）

[← 选风格索引](../index.md) · [提示词方法](../prompting.md) · [技术标签](../tags.md)

用代码驱动专业软件出画面，例如用 Python 脚本操作 Blender 建模、布光、渲染。

每个条目依次是：样片缩略图（已渲染的才有）、一句可直接复制的风格提示词、题材、适合讲什么、技术标签、参考链接。「技术（已验证）」表示仓库里有真能跑出这段样片的代码；「技术（建议）」是推荐写法，还没有样片验证。

<a id="C-071"></a>

## C-071 Blender 程序化场景

```text
用 Blender 程序化建模风格：用 Python 脚本从零搭建场景、不用任何预制资产，夜景湖面倒影、远山和烟花，先出灰模和镜头预览再上材质和灯光，另外录一段从灰模到成片的建造延时。
```

- 题材：3D 与实时图形
- 适合：建筑、城堡、机械
- 技术（建议）：Blender
