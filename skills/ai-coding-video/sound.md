[← 返回说明](README.md)

## 声音篇：总原则

声音分两层：背景层（配乐、环境声、动作音效）和人声层（旁白、对话）。公开风格库的导演指南（见 [sources.md](sources.md)）把声音排在评判标准的第一位，下面 7 条是从各风格的声音设计里提炼的通用做法。

1. **先定音乐时间轴，再做画面**：切点、关键动作、字幕出现都落在拍子上，音乐和画面共用一份时间表。
2. **每个看得见的动作都要有声音，音效跟材质走**：纸、木、金属、墨、玻璃、塑料各有各的声音。
3. **静音是工具**：高潮或笑点前给一拍真正的静音，连混响尾巴一起切掉。
4. **别用万能铺底**：避开“钢琴 + 弦乐”通用配乐和廉价的“嗖”声（卡通类除外），换成这种风格自己的乐器。
5. **混音层级**：人声在最上层；有人声时音乐压低 8–12 dB、环境声压低 3–6 dB；整体响度 −14 LUFS。
6. **旁白要回听校对**：生成后用 Whisper 转写，每句都要听写正确；多音字、数字、人名先改写再合成。
7. **版权**：音乐和音效优先用代码合成，其次是 CC0、CC BY 或已购授权的曲库，并在片尾或说明里列出来源。

## 背景音乐与音效：按风格类别匹配

先按风格条目的「题材」找到一行，再把这一行写进提示词的“声音”部分。括号里是该类别中具体风格的实测做法。

| 风格类别 | 配乐（乐器与节奏） | 环境声 | 动作音效 |

| 东方传统 | 民族乐器（皮影用锣鼓经，窗花剪纸用琵琶、古筝、二胡的喜庆室内乐，浮世绘用三味线、尺八、太鼓，纸雕灯影用古筝接笛子） | 夜虫、油灯噼啪、远处爆竹 | 剪刀、纸张折合、醒木、竹杆敲布幕 |

## 旁白配音：Kokoro-82M v1.1-zh 音色总览

Kokoro-82M v1.1-zh 是一个可以在本地 CPU 上跑的开源 TTS 模型（Apache 2.0，24 kHz），共 103 个音色：100 个中文音色来自龙猫数据的 100 位专业说话人，另有 3 个英文音色。

| 前缀 | 数量 | 说明 |
|---|---|---|
| zf_ | 55 | 中文女声，编号不连续（zf_001–zf_099 中的 55 个） |
| zm_ | 45 | 中文男声（zm_009–zm_100 中的 45 个） |
| af_maple · af_sol | 2 | 美式英语女声 |
| bf_vale | 1 | 英式英语女声，官方描述为“年长的英国女性” |

**官方没有给每个中文音色写描述，音色名只是编号。** 为了能区分，我用同样两段文字（一段科普讲解、一段童话叙述）把 100 个中文音色全部合成一遍（语速都设为 1.0），测了四项指标并分档：

- **音高档**：基频中位数。女声分低音（低于 200 Hz）、中低音、中音、中高音、高音（280 Hz 以上）；男声分低沉（低于 120 Hz）、中低音、中音、中高音、高音少年感（190 Hz 以上）。
- **语调**：句子里音高起伏的幅度。平稳适合播报和讲解，起伏大适合讲故事和角色。
- **语速**：同样文字每秒读出的字数，分偏快、中等、偏慢。
- **声音明暗**：高频多少。偏暗的听起来更柔或更厚，偏亮的更清脆。

这是声学测量结果，不包含年龄感、亲和力这类主观印象。定音色前请先到 [sherpa-onnx 试听页](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html) 听一遍候选，那里每个音色都有同一段文字的试听（页面用编号标注：3–57 是 zf_，58–102 是 zm_，各自按音色名从小到大排列，如 3 是 zf_001、58 是 zm_009）。

## 对话与多角色配音

有对话时，关键是让观众闭着眼睛也能分清谁在说话。

1. **旁白和角色分开**：旁白用平稳的中音，角色用起伏大的音色。
2. **角色之间至少隔一个音高档**：如高音女声配低沉男声，或高音女声配中低音女声；同一档的两个音色很难分辨。
3. **同一角色全片固定音色和语速**，写进角色设定表。
4. **每句台词单独生成一个文件**，句间留 0.2–0.4 秒，方便对字幕和口型。
5. **情绪靠文案和节奏**：Kokoro 不会耳语、喊叫、哭或唱歌。害怕就用短句、慢语速、多停顿；兴奋就用感叹句和稍快语速。
6. **非人类角色**（机器人、吉祥物、游戏角色）可以不用人声：用打字“哔哔”声，或给合成人声加环形调制、带通滤波。

## 旁白提示词与调用代码

把下面这段加到前面通用模板的“声音”一行，把音色和语速换成上面表里选好的：

```text
声音：配乐用【风格类别对应的乐器】，音效跟画面材质走，高潮前留一拍静音。
旁白用本地 Kokoro-82M-v1.1-zh，音色【zf_083】，语速【0.95】；共【4–6】句，每句不超过 20 字，每句单独生成一个文件。
长句按官方示例的 speed_callable 自动放慢，避免抢拍；多音字、数字、英文先改写成不会读错的写法。
有旁白时音乐压低 9 dB、环境声压低 4 dB，整体 −14 LUFS。生成后用 Whisper 回听，每句都要听写正确才能进成片。
```

调用代码（按官方示例 make_zh.py 整理，需要 `pip install kokoro>=0.8.1 "misaki[zh]>=0.8.1"`）：

```python
from kokoro import KModel, KPipeline
import soundfile as sf

REPO_ID = 'hexgrad/Kokoro-82M-v1.1-zh'
model = KModel(repo_id=REPO_ID).eval()
en = KPipeline(lang_code='a', repo_id=REPO_ID, model=False)
zh = KPipeline(lang_code='z', repo_id=REPO_ID, model=model,
               en_callable=lambda t: next(en(t)).phonemes)  # 句中的英文单词

def speed(len_ps, base=1.0):
    # 官方示例：超过约 100 个音素会抢拍，越长越放慢
    s = 1.0 if len_ps <= 83 else (1 - (len_ps - 83) / 500 if len_ps < 183 else 0.8)
    return s * 1.1 * base

lines = ['天空为什么是蓝色的？', '阳光其实是七种颜色混在一起。']
for i, line in enumerate(lines):
    audio = next(zh(line, voice='zf_083', speed=lambda n: speed(n, 0.95))).audio
    sf.write(f'vo_{i:02}.wav', audio, 24000)
```

小贴士：同一句话换音色对比时，只改 `voice` 参数即可；音色文件在模型仓库的 voices 文件夹里，首次使用会自动下载。
